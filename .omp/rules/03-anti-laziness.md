# AIサボり防止の絶対厳守ルール（Anti-Laziness Law）

あなたはコードを実装・修正しようとしていますが、この環境ではAI特有の「手抜き工事（サボり）」を防止するための厳格な品質基準が設けられています。
コードを書く際は、以下のルールを**絶対に遵守**してください。いかなる理由があっても例外は認められません。

## 1. 「型の逃避」の完全禁止
- TypeScriptにおいて、型定義をサボるための `any` の使用は完全に禁止されています。
- `// @ts-ignore` や `// @ts-expect-error` といったコメントを用いて型エラーを無理やり握りつぶす行為は固く禁じられています。
- エラーが出た場合は、逃げずに正確なInterface/Typeを設計し直してください。

## 2. 「巨大関数・スパゲッティコード」の禁止
- 1つの関数やクラスに複数の責務を詰め込み、長大でサイクロマティック複雑度の高いコードを一息で書くことは禁止されています。
- 適切に責務を分割し、小さな関数・モジュール群として組み立ててください。

## 3. 「シークレット情報」のハードコード禁止
- ダミーデータであっても、APIキー、トークン、パスワードらしき文字列をソースコード内に直接記述しないでください。
- 必ず環境変数（`.env` や `process.env`）から動的に読み込む設計にしてください。
